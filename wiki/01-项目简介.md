# 项目简介

## 项目定位

**VALKYRIE DB**（瓦尔基里数据库管理工具）是一款基于 JavaFX 的跨平台多数据库管理桌面客户端工具，类似于 DBeaver、Navicat 等工具。它提供统一的界面来管理多种数据库系统，支持 SQL 编辑、数据浏览、表结构设计、数据导入导出等核心功能。

- **GroupId**: `com.changhong.valkyrie`
- **当前版本**: v1.6.0
- **作者**: Luo Tiansheng (luots@vip.qq.com)
- **项目类型**: 桌面应用程序（Desktop Application）

## 核心特性

### 多数据库支持
统一连接和管理多种数据库系统：
- MySQL 8.x
- PostgreSQL 42.x
- SQLite 3.x
- 达梦数据库 (DM) 8.x
- Redis 7.x

### SQL 编辑与执行
内置功能强大的数据库查询编辑器：
- SQL 语法高亮
- 自动补全及关键字去重
- 查询执行及终止
- 提示显示表注释、字段注释
- 支持 Monaco Editor 快捷键（Ctrl+C/X/D/Shift+U 等）
- 异步执行，不阻塞 UI

### 可视化数据管理
直观的数据浏览与编辑能力：
- 表格数据视图，支持空值/空字符串显示区分
- 表结构设计，支持字段、索引、默认值、主键、自增列
- 数据浏览与多节点层级结构展示
- 支持实时编辑与自动提交
- 右键菜单支持复制为 INSERT/UPDATE/JSON 语句

### 数据导入与导出
- Excel 导出（基于 Apache POI）
- 批量导入/导出
- 数据备份与迁移

### 工作区与日志管理
- 支持标签页自由拖动及关闭联动
- 异步加载表数据和节点，避免 UI 卡顿
- 查询日志高亮显示
- 错误提示支持复制和智能解释
- 全局状态栏显示当前执行的 SQL 语句
