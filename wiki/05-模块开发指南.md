# 模块开发指南

## 新增数据库驱动

以添加一个新数据库支持为例，说明开发步骤。

### 步骤 1：在 DbType 枚举中添加类型

编辑 `drivers/src/main/java/valkyrie/driver/api/DbType.java`：

```java
public enum DbType {
    MYSQL("mysql", "MySQL", "mysql.png", "com.mysql.cj.jdbc.Driver", true),
    POSTGRESQL("postgresql", "PostgreSQL", "postgresql.png", "org.postgresql.Driver", true),
    SQLITE("sqlite", "SQLite", "sqlite.png", "org.sqlite.JDBC", true),
    DM("dm", "达梦", "dm.png", "dm.jdbc.driver.DmDriver", true),
    REDIS("redis", "Redis", "redis.png", null, false),
    // 新增数据库
    ORACLE("oracle", "Oracle", "oracle.png", "oracle.jdbc.OracleDriver", true);
    
    // ...
}
```

### 步骤 2：实现 Dialect 方言

创建 `drivers/src/main/java/valkyrie/driver/dialect/OracleDialect.java`：

```java
public class OracleDialect implements Dialect {
    @Override
    public String limit(String sql, long offset, long size) {
        // Oracle 分页语法
        return String.format("SELECT * FROM (%s) WHERE ROWNUM BETWEEN %d AND %d", 
            sql, offset + 1, offset + size);
    }
    
    @Override
    public String quote(String identifier) {
        return "\"" + identifier + "\"";
    }
    
    @Override
    public String removeQuote(String identifier) {
        return identifier.replace("\"", "");
    }
}
```

### 步骤 4：在 DbType 中注册驱动工厂

在 `DbType` 枚举中添加驱动创建方法：

```java
ORACLE("oracle", "Oracle", "oracle.png", "oracle.jdbc.OracleDriver", true) {
    @Override
    public Driver createDriver(VkDataSource dataSource) {
        return new OracleDriver(dataSource);
    }

```

### 步骤 5：添加 Maven 依赖


## 新增 UI 控件

所有自定义 UI 控件使用 `Vk` 前缀，放在 `app/src/main/java/valkyrie/app/widgets/` 包下。

### 示例：创建 VkCustomButton

```java
package valkyrie.app.widgets;

import javafx.scene.control.Button;

public class VkCustomButton extends Button {
    
    public VkCustomButton() {
        initialize();
    }
    
    public VkCustomButton(String text) {
        super(text);
        initialize();
    }
    
    private void initialize() {
        getStyleClass().add("vk-custom-button");
        // 设置默认样式

```

在 CSS 文件中添加样式：

```css
.vk-custom-button {
    -fx-background-color: -vk-primary-color;

    -fx-background-radius: 4;
    -fx-padding: 6 12;
}
```

## 事件总线使用

### 定义事件

```java
public class ConnectionChangedEvent implements Event {
    private final ConnectionProfile profile;
    
    public ConnectionChangedEvent(ConnectionProfile profile) {
        this.profile = profile;
    }
    
    public ConnectionProfile getProfile() {
        return profile;
    }
}
```

### 发布事件

```java
eventBus.publish(new ConnectionChangedEvent(profile));
```

### 订阅事件

```java
eventBus.subscribe(ConnectionChangedEvent.class, event -> {
    // 处理事件
    refreshConnectionList(event.getProfile());
});
```

## 异步任务规范

### 使用 ExecutorService

```java
// 在 App 中创建单线程执行器
private final ExecutorService sqlExecutor = Executors.newSingleThreadExecutor(r -> {
    Thread t = new Thread(r, "sql-executor");
    t.setDaemon(true);
    return t;
});

// 提交任务
sqlExecutor.submit(() -> {
    try {
        QueryResult result = driver.selectByPage(session, sql, 0, 100);
        Platform.runLater(() -> displayResult(result));
    } catch (Exception e) {
        Platform.runLater(() -> showError(e));
    }
});
```

### 支持取消

```java
String jobId = UUID.randomUUID().toString();
sqlExecutor.submit(() -> {
    driver.execute(jobId, session, sql, callback);
});

// 取消
driver.cancel(jobId);
```
