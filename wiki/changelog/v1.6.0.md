# v1.6.0 更新日志

## ⭐ 新增功能

- 支持 `SQLite` 数据库
- 支持 `PostgreSQL` 数据库
- 新增数据表格右键菜单，支持复制为 `INSERT` 和 `UPDATE` 语句
- 新增全局状态栏，显示当前正在执行的 `SQL` 语句
- 新增执行查询、更新等语句日志显示以及执行耗时
- 支持代码编辑器中选中表时添加 `打开设计表` 右键菜单
- 支持代码编辑器自动保存数据到文件
- 新增右键菜单弹出动画
- 新增已保存的查询脚本文件详细信息列表面板
- 支持数据表格复制为 `JSON` 格式

## 👻 优化功能

- 优化高分辨率下图标模糊问题
- 优化了右键菜单样式，新增圆角边框、模糊等效果
- 优化树节点渲染逻辑，支持动态节点渲染
- 优化查询脚本保存以及节点联动功能
- 优化代码补全逻辑，使用异步加载，避免创建编辑器卡顿
- 优化节点加载逻辑，避免重复双击导致节点多次加载
- 优化数据表格奇数偶数行背景色以及表格选中样式
- 优化导航树节点选中样式以及选中背景色

## 🐞 BUG 修复

- 修复 Windows 下无法打开文件所在目录问题
- 修复 Windows 下无法复制粘贴问题 (#BUG-0043)
- 修复切换连接时，新建查询编辑器未自动切换数据库 (#BUG-0044)
- 修复树节点不支持中文搜索 (#BUG-0045)

## 已知问题

- Tab 标签关闭后对象仍被引用导致无法回收 (#BUG-0046)
