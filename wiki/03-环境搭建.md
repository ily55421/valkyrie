# 环境搭建

## 前置要求

| 工具 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 21+ | 推荐使用 Eclipse Temurin 或 Oracle JDK 21 |
| Maven | 3.9.x | 项目构建工具 |
| Git | 任意 | 版本控制 |
| Node.js | 18+ | 仅 workflow-editor 前端开发需要 |

## 开发环境配置

### 1. 安装 JDK 21

**Windows:**
```powershell
# 使用 winget 安装
winget install EclipseAdoptium.Temurin.21.JDK

# 或手动下载安装
# https://adoptium.net/temurin/releases/?version=21
```

**macOS:**
```bash
brew install openjdk@21
```

**Linux:**
```bash
# Ubuntu/Debian
sudo apt install openjdk-21-jdk
```

验证安装：
```bash
java -version
# 应输出 openjdk version "21.x.x"
```

### 2. 安装 Maven

**Windows:**
```powershell
winget install Apache.Maven
```

**macOS:**
```bash
brew install maven
```

验证安装：
```bash
mvn -version
# 应输出 Apache Maven 3.9.x
```

### 3. 克隆项目

```bash
git clone <repository-url>
cd valkyrie
```

## 构建项目

### 完整构建

```bash
mvn clean package
```

构建产物位于 `launcher/target/` 目录下，可执行 fat-jar 名称类似：
```
valkyrie-launcher-v1.0.0-arch.1.jar
```

### 跳过测试构建

```bash
mvn clean package -DskipTests
```

### 单独构建模块

```bash
# 构建 utils 模块
mvn clean install -pl utils

# 构建 drivers 模块（依赖 utils）
mvn clean install -pl drivers -am

# 构建 app 模块（依赖 core/drivers/monacofx 等）
mvn clean install -pl app -am
```

## 运行应用

### 方式一：Maven 运行

```bash
cd launcher
mvn exec:java -Dexec.mainClass="valkyrie.Launcher"
```

### 方式二：直接运行 JAR

```bash
java -jar launcher/target/valkyrie-launcher-*.jar
```

### 方式三：IDE 运行

在 IDE 中直接运行 `launcher/src/main/java/valkyrie/Launcher.java` 的 `main()` 方法。

**推荐 IDE：**
- IntelliJ IDEA（推荐，对 JavaFX 支持最好）
- Eclipse（需安装 e(fx)clipse 插件）
- VS Code（需安装 Java Extension Pack）

### IDEA 运行配置

1. 打开项目结构设置（File → Project Structure）
2. 设置 Project SDK 为 JDK 21
3. 设置 Language level 为 21
4. 找到 `Launcher.java`，右键 → Run 'Launcher.main()'

## 前端开发（workflow-editor）

`workflow-editor/` 是独立的 React 前端项目，用于工作流编辑器功能。

### 安装依赖

```bash
cd workflow-editor
npm install
```

### 开发模式

```bash
npm run dev
```

### 构建

```bash
npm run build
```

构建产物会输出到 `blueprint/` 模块的资源目录中，供 JavaFX WebView 加载。

## 打包发布

### macOS 打包

项目使用 `jpackage` 工具打包原生应用：

```bash
# buildSrc/ 目录包含 macOS 打包脚本
cd buildSrc
# 执行打包脚本（需根据环境配置）
```

### Windows 打包

```powershell
# 使用 jpackage 打包
jpackage `
  --input launcher/target `
  --main-jar valkyrie-launcher-*.jar `
  --main-class valkyrie.Launcher `
  --name VALKYRIE `
  --type exe `
  --java-options "--add-opens=java.base/java.lang=ALL-UNNAMED"
```

## 常见问题

### JavaFX 运行时错误

如果出现 `Error: JavaFX runtime components are missing`：

确保 Maven 依赖中包含 JavaFX 依赖，或在运行时添加 JavaFX SDK：

```bash
java --module-path /path/to/javafx-sdk-21/lib \
  --add-modules javafx.controls,javafx.fxml,javafx.web,javafx.graphics \
  -jar valkyrie-launcher-*.jar
```

### 模块找不到错误

首次构建时如果出现模块找不到，先执行完整安装：

```bash
mvn clean install -DskipTests
```

### 中文乱码问题

确保 JVM 启动参数包含 UTF-8 编码：

```bash
java -Dfile.encoding=UTF-8 -jar valkyrie-launcher-*.jar
```

## JVM 参数调优

项目根目录提供 `VM.flags` 文件作为参考：

```
-Xms256m
-Xmx2048m
-XX:+UseG1GC
-XX:MaxGCPauseMillis=200
-Dfile.encoding=UTF-8
--add-opens=java.base/java.lang=ALL-UNNAMED
--add-opens=java.base/java.nio=ALL-UNNAMED
```
