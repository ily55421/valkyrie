# 数据浏览与编辑

## 功能概述

数据网格（DataGrid）组件提供直观的表格数据浏览和编辑功能，支持直接在界面上查看和修改数据库数据。

## 数据浏览

### 打开表数据

在导航树中双击表节点，或右键选择 **查看数据**，打开数据浏览标签页。

### 显示特性

- **空值区分**：`NULL` 值显示为灰色斜体 `NULL`，空字符串显示为空白
- **行号**：左侧显示行号
- **列类型提示**：列标题悬停显示列数据类型
- **奇偶行**：奇偶行使用不同背景色，提高可读性
- **选中高亮**：选中行/单元格高亮显示

### 分页加载

- 默认加载前 1000 行
- 支持分页查询
- 大数据集异步加载，不阻塞 UI

## 数据编辑

### 可编辑条件

结果集满足以下条件时支持直接编辑：
- 查询包含主键列
- 单表查询（非 JOIN 查询）
- 驱动支持该数据库的编辑操作

### 编辑操作

1. **修改单元格**：双击单元格进入编辑模式，修改后自动标记为已更新
2. **新增行**：点击工具栏新增按钮，在末尾添加空行
3. **删除行**：选中行后点击删除按钮
4. **提交更改**：点击提交按钮将所有更改写入数据库
5. **回滚更改**：放弃未提交的修改

### SQL 自动生成

编辑操作自动生成对应的 SQL：
- **修改** → `UPDATE table SET col=? WHERE pk=?`
- **新增** → `INSERT INTO table (col1, col2) VALUES (?, ?)`
- **删除** → `DELETE FROM table WHERE pk=?`

使用 JSqlParser 解析和生成 SQL，确保语法正确。

## 右键菜单

在数据网格中右键：

| 菜单项 | 功能 |
|--------|------|
| 复制单元格 | 复制选中单元格值 |
| 复制行 | 复制整行数据 |
| 复制为 INSERT | 生成 INSERT 语句 |
| 复制为 UPDATE | 生成 UPDATE 语句 |
| 复制为 JSON | 复制为 JSON 格式 |
| 导出 Excel | 导出数据到 Excel 文件 |
| 刷新 | 重新加载数据 |

### 复制格式示例

**复制为 INSERT**:
```sql
INSERT INTO users (id, name, email) VALUES (1, '张三', 'zhangsan@example.com');
```

**复制为 UPDATE**:
```sql
UPDATE users SET name='张三', email='zhangsan@example.com' WHERE id=1;
```

**复制为 JSON**:
```json
{
  "id": 1,
  "name": "张三",
  "email": "zhangsan@example.com"
}
```

## 数据导出

支持将查询结果导出为 Excel 文件：
- 使用 Apache POI 生成 `.xlsx` 格式
- 保留列名作为表头
- 支持大数据量导出
