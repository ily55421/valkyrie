# 数据导入导出

## 功能概述

VALKYRIE DB 提供数据导入导出功能，支持 Excel 等格式的数据交换。

## 数据导出

### Excel 导出

将查询结果或表数据导出为 Excel 文件（`.xlsx`）。

**操作步骤**：
1. 打开表数据或执行查询
2. 在数据网格中右键 → **导出 Excel**
3. 选择保存路径
4. 等待导出完成

**导出特性**：
- 使用 Apache POI 生成 `.xlsx` 格式
- 第一行为列名（表头）
- 保留数据类型（数字、日期、字符串）
- 支持大数据量导出
- NULL 值导出为空单元格

### 复制导出

通过右键菜单快速复制数据：

| 格式 | 说明 |
|------|------|
| INSERT 语句 | 生成标准 INSERT INTO 语句 |
| UPDATE 语句 | 生成 UPDATE ... WHERE 语句 |
| JSON 格式 | 复制为 JSON 对象/数组 |

## 数据导入

支持从外部文件批量导入数据到数据库表。

### 支持的导入格式

- Excel 文件（`.xlsx`, `.xls`）
- CSV 文件
- SQL 脚本（INSERT 语句）

### 导入流程

1. 选择目标表
2. 选择导入文件
3. 映射列（文件列 → 表列）
4. 预览导入数据
5. 执行导入

## 批量操作

### 批量导出

支持多表批量导出：
- 选择多个表
- 批量导出为 Excel（每个表一个 Sheet）
- 或导出为 SQL 脚本

### 备份与迁移

- 导出数据库结构（CREATE TABLE 语句）
- 导出完整数据（INSERT 语句）
- 支持跨数据库迁移（不同数据库类型之间）

## 技术实现

### Excel 处理

使用 Apache POI 5.3.0：
- `XSSFWorkbook` 处理 `.xlsx`
- `HSSFWorkbook` 处理 `.xls`
- 流式写入支持大文件

### SQL 生成

使用 JSqlParser 生成标准 SQL：
- 根据数据库类型生成对应方言的 SQL
- 处理标识符转义
- 处理特殊字符转义
