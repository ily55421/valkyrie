# 数据库连接管理

## 功能概述

VALKYRIE DB 支持管理多种数据库的连接配置，连接信息以 JSON 格式持久化存储在本地用户目录。

## 创建连接

1. 点击菜单栏 **连接 → 新建连接** 或点击工具栏新建按钮
2. 在弹出的对话框中配置连接信息：
   - **常规选项卡**：
     - 连接名称
     - 数据库类型（MySQL/PostgreSQL/SQLite/达梦/Redis）
     - 主机地址
     - 端口
     - 数据库名
     - 用户名/密码
   - **高级选项卡**：
     - 自定义 JDBC URL
     - 连接属性
3. 点击 **测试连接** 验证配置
4. 点击 **确定** 保存连接

## 连接管理

### 导航树结构

连接创建后在左侧对象浏览器中显示：

```
📁 连接名称 (MySQL)
├─ 📁 database_1
│  ├─ 📁 表
│  │  ├─ 📄 users
│  │  └─ 📄 orders
│  ├─ 📁 视图
│  └─ 📁 已保存查询
│     └─ 📝 query_1
└─ 📁 database_2
```

### 右键菜单

在连接节点上右键：
- **连接/断开**：打开或关闭数据库连接
- **编辑连接**：修改连接配置
- **删除连接**：删除连接配置
- **刷新**：重新加载数据库对象
- **新建查询**：打开 SQL 编辑器

### 表节点右键菜单

- **查看数据**：打开表数据浏览（前1000行）
- **设计表**：打开表结构设计器
- **复制为 INSERT**：生成 INSERT 语句
- **复制为 UPDATE**：生成 UPDATE 语句
- **复制为 JSON**：将表结构复制为 JSON 格式

## 连接存储

连接配置存储在：
- **Windows**: `C:\Users\<用户名>\.valkyries\C\connections.json`
- **macOS/Linux**: `~/.valkyries/C/connections.json`

## 连接池

使用 HikariCP 连接池管理数据库连接：
- 最大连接数：16
- 最小空闲：1
- 连接超时：30秒
- 空闲超时：10分钟
- 最大生命周期：30分钟
