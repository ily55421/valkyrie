# SQL 编辑器

## 功能概述

SQL 编辑器基于 Monaco Editor（VS Code 使用的编辑器），提供专业的 SQL 编写和执行环境。

## 核心功能

### 语法高亮

支持 SQL 语法高亮显示，关键字、字符串、数字、注释等使用不同颜色区分。

### 自动补全

编辑器提供智能自动补全：
- SQL 关键字（SELECT、FROM、WHERE、INSERT 等）
- 表名（当前数据库的表）
- 列名（当前选中表的列）
- 函数名
- 补全项去重

### 执行查询

- 点击工具栏 **执行** 按钮或按快捷键执行 SQL
- 支持选中部分 SQL 执行
- 支持多条 SQL 语句批量执行
- 执行结果在下方结果面板显示

### 取消查询

- 执行中的查询可以点击 **取消** 按钮终止
- 基于 jobId 机制取消独立查询任务

### 执行日志

- 显示 SQL 执行历史
- 显示每条语句的执行耗时
- 错误信息高亮显示
- 支持复制错误信息

### 快捷键

支持 Monaco Editor 标准快捷键：

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Enter | 执行 SQL |
| Ctrl+C | 复制 |
| Ctrl+X | 剪切 |
| Ctrl+V | 粘贴 |
| Ctrl+D | 选中下一个匹配项 |
| Ctrl+Shift+U | 转换为大写 |
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |
| Ctrl+F | 查找 |
| Ctrl+H | 替换 |
| Ctrl+/ | 注释/取消注释 |
| Ctrl+S | 保存脚本 |

### 脚本保存

- SQL 脚本可以保存到本地
- 保存的脚本在导航树"已保存查询"节点下显示
- 支持重命名、删除已保存脚本
- 编辑器内容自动保存

### 右键菜单

在编辑器中右键：
- **执行**：执行选中的 SQL
- **格式化**：格式化 SQL
- **打开设计表**：选中文本表名时打开表设计器
- **复制**、**剪切**、**粘贴**

## 异步执行

所有 SQL 操作在独立线程执行，不阻塞 UI：
1. SQL 提交到单线程执行器
2. 状态栏显示"正在执行..."
3. 执行完成后更新结果面板
4. 执行期间 UI 保持响应

## 结果展示

查询结果以表格形式展示：
- 列标题显示列名
- 支持排序（点击列标题）
- 空值显示为 `NULL`（灰色）
- 空字符串显示为空白
- 支持直接编辑结果集（对于可编辑查询）
