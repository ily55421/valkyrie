# 表结构设计器

## 功能概述

表设计器提供可视化的表结构创建和编辑功能，支持字段、索引、主键、默认值等的设计。

## 打开方式

- 右键表节点 → **设计表**
- 在 SQL 编辑器中选中文本表名 → 右键 → **打开设计表**
- 新建表时自动打开

## 列设计

### 列属性

| 属性 | 说明 |
|------|------|
| 列名 | 字段名称 |
| 类型 | 数据类型（INT, VARCHAR, TEXT, DATETIME 等） |
| 非空 (NOT NULL) | 是否允许 NULL 值 |
| 主键 (PRIMARY KEY) | 是否为主键列 |
| 自增 (AUTO_INCREMENT) | 是否自动递增 |
| 默认值 | 列默认值 |
| 注释 | 列注释/说明 |

### 操作

- **添加列**：点击添加按钮在末尾新增列
- **删除列**：选中列后点击删除
- **上移/下移**：调整列顺序

## 索引设计

切换到 **索引** 选项卡管理索引：

| 属性 | 说明 |
|------|------|
| 索引名 | 索引名称 |
| 列 | 索引包含的列 |
| 类型 | 索引类型（普通/唯一/全文等） |
| 可见 | 索引是否可见 |

### 索引类型支持

不同数据库支持的索引类型不同：
- MySQL：INDEX, UNIQUE, FULLTEXT, PRIMARY KEY
- PostgreSQL：INDEX, UNIQUE, PRIMARY KEY
- SQLite：INDEX, UNIQUE, PRIMARY KEY

## 保存更改

点击 **保存** 按钮时：
1. 对比原始结构和修改后的结构
2. 自动生成 ALTER 语句
3. 执行 DDL 应用更改

### 自动生成的 DDL

| 操作 | 生成的 SQL |
|------|-----------|
| 新增列 | `ALTER TABLE t ADD COLUMN ...` |
| 修改列 | `ALTER TABLE t MODIFY COLUMN ...` / `ALTER TABLE t ALTER COLUMN ...` |
| 删除列 | `ALTER TABLE t DROP COLUMN ...` |
| 新增索引 | `CREATE INDEX ... ON t (...)` |
| 删除索引 | `DROP INDEX ...` |
| 新增主键 | `ALTER TABLE t ADD PRIMARY KEY (...)` |
| 删除主键 | `ALTER TABLE t DROP PRIMARY KEY` |

## 完整性校验

列和索引对象使用 `Sealable` 基类提供完整性校验：
- 对象加载时计算完整性码
- 修改时检测是否被篡改
- 防止并发修改冲突
