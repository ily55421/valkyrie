# 开发环境规范

## JDK 配置

**强制使用 JDK 21**，路径：

```
D:\dev\Java\jdk-21.0.10_windows-x64_bin\jdk-21.0.10
```

### PowerShell 构建命令

构建/运行前必须设置 JAVA_HOME：

```powershell
$env:JAVA_HOME = "D:\dev\Java\jdk-21.0.10_windows-x64_bin\jdk-21.0.10"
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
```

### 常用命令

```powershell
# 编译
mvn clean compile -DskipTests

# 打包
mvn package -DskipTests

# 安装到本地仓库
mvn install -DskipTests

# 启动应用
java -jar launcher/target/launcher-v1.0.0-arch.1.jar
```

## 构建要求

- JDK 21
- Maven 3.9.x
- OpenJFX 21+（通过 Maven 依赖引入）

## 注意事项

- 父 POM 中已显式配置 `<source>21</source><target>21</target><release>21</release>`
- 资源加载（图片、CSS）已兼容 jar 包环境，支持按需加载
